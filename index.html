개인 PC에서 관리하는
YouTube 다시보기 업로더

사용자가 지정한 PC 폴더의 영상을 날짜순으로 관리하고 본인 YouTube 채널에 업로드하는 개인용 프로그램입니다.

이 사이트는 프로그램 소개와 데이터 처리 안내만 제공합니다. 로그인이나 영상 업로드 기능은 없습니다. 업로더 본체와 영상 목록은 사용자의 PC에서 관리합니다.

주요 기능

  • 선택한 폴더의 영상 목록·길이·작업 순서 관리
  • 본인 채널 영상 업로드, 제목·설명·썸네일·공개 상태 설정
  • YouTube API 및 Studio 연결 확장프로그램을 통한 처리 상태·저작권 차단 정보 확인
  • 설정에 따른 분할·병합·차단 구간 제거, 로컬 썸네일 제작 및 재생목록 분류

개인정보처리방침

시행일: 2026년 11월 13일
적용 대상: Hanryang Archive Uploader 개인용 PC 프로그램 및 Studio 검사 연결 확장프로그램

1. 사용하는 정보와 목적

Google 승인으로 발급되는 인증 정보, 연결한 YouTube 채널 식별자·이름, 영상 식별자·제목·설명·공개 상태·처리 상태·재생목록 정보를 사용합니다. Studio 확장프로그램은 검사 상태와 차단 구간 정보를 PC 업로더에 전달합니다. 계정 연결, 중복 업로드 방지, 작업 재개, 저작권 검사 및 영상·재생목록 관리에 사용합니다.

지정한 PC 영상 파일과 경로, 파일명·크기·길이, 썸네일과 분석 결과, 설정 및 작업 로그도 처리합니다. Google 비밀번호를 업로더에 입력하거나 저장하지 않습니다.

2. 저장과 전송

설정·진행 기록·분석 결과·썸네일 등은 사용자 PC의 프로그램 및 데이터 폴더에 저장합니다. 인증 갱신 정보는 Windows 사용자 계정 기반 암호화로 보호합니다. Google 인증과 YouTube 기능에 필요한 요청, 업로드 영상·썸네일·제목·설명·재생목록 변경은 Google/YouTube로 전송합니다. Studio 검사 결과는 PC에서 실행 중인 로컬 업로더로 전달됩니다.

현재 썸네일 생성과 영상 내용 분석은 PC의 로컬 제작기를 이용합니다. Google 사용자 데이터를 광고 목적으로 판매하거나 범용 AI 모델 학습·개선에 사용하지 않습니다. 외부 처리 서비스가 추가되는 경우 목적과 전송 대상을 별도로 안내합니다.

3. 보관과 삭제

작업 재개를 위해 로컬 기록과 백업을 보관합니다. 프로그램 종료 후 PC의 관련 데이터와 백업을 삭제할 수 있습니다. Google 계정의 연결된 앱 관리에서 접근 권한을 철회할 수 있습니다. 권한 철회만으로 PC 기록이나 이미 업로드한 영상이 삭제되지는 않습니다. YouTube 영상은 YouTube에서 별도로 관리·삭제할 수 있습니다.

4. Google 사용자 데이터 제한적 사용

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 안내 사이트

별도의 계정 입력 폼이나 방문 분석 스크립트를 넣지 않았습니다. 무료 호스팅 서비스 GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록할 수 있습니다. 해당 처리는 GitHub 개인정보처리방침을 따릅니다.

이용 안내

본인 채널과 적법하게 이용할 권한이 있는 영상을 관리하는 개인용 도구이며 Google 또는 YouTube의 공식 제품이 아닙니다. 업로드 대상·공개 설정·저작권을 확인해야 합니다. 저작권 검사 결과는 이후 변경될 수 있습니다. 정책 변경, 권한 철회, 네트워크 장애 등으로 재승인 또는 사용자 확인이 필요할 수 있습니다.
